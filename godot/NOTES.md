## Roadmap step 3 — breakable parts (MechDuel, --breakable-test)

- MechParts.cs: per-mech part registry. Parts are sets of the FBX's MeshInstance3D nodes (every mesh is rigidly bound to one bone; mapping by node name + dominant skin bone). Part HP per spec: pods 45, arms 65, legs 90, head 50; torso = the main HP pool. Head hits burn head HP AND the pool x1.0. Because both kits merge ears/canopy/skull into ONE Torso mesh, the TW pods + head and the Atlas skull are split out at runtime by triangle-centroid region in model space; split pieces keep the original skin/skeleton/tree spot.
- Hit attribution, two layers: (1) HitModel.Ray now also tests per-part bone-space boxes (slab test in each bone's frame, affine-preserves the ray parameter) so aimed fire registers on parts that protrude outside the capsule (arms, pods) — the capsule alone sails past an arm ~5u off-axis. The torso is excluded from the box test (its core AABB slab would shadow the shoulder boxes; the capsule is the torso's volume). (2) Capsule points / splash / crafted hits attribute by nearest part volume via per-mesh box SDF in bone space. ApplyDamage trusts a box-ray part; otherwise it resolves by SDF — an interior point can sit inside a neighbor's AABB (the TW canopy vs the torso core), a surface point cannot.
- Break-off: meshes detach with the skinless-equivalent transform (meshGlobal * bonePose * bindPose — reproduces skinned vertices at the detach instant), then debris under gravity 20, outward impulse 2.0 + up 2.8, tumble, one bounce (restitution 0.22), settle judged at the AABB's lowest (downhill) corner, then permanent non-colliding rest. Reset (R) rebinds meshes to the stored parent/transform/skin/skeleton, frees debris, refills HP — idempotent.
- Consequences (live gates, no snapshots): TW arm_L lost -> laser offline; arm_R lost -> AC offline AND Atlas AC/20 offline; denied fire logs + flashes the cooldown bar red, costs no cooldown. Pods: salvo = 4 per live pod, both gone -> LRM denied. Leg lost (MechWalker): the leg never steps, its foot target rides locked at its rest slot on the terrain (drag), SpeedFactor 0.55, LimpRoll 0.13 rad toward the dead side; both legs -> the existing Die() path (halt + droop + banner). Atlas head lost: AC/20 spread 1.2 -> 3.6 deg, torso tracking capped at 0.6 rad/s (lag). Player head lost: 1.2s HUD flicker at the break + persistent crosshair sway (sin 1.9/2.7 Hz, 13x9 px). HUD: event feed (last 5, 6s each), destroyed mounts pin their cooldown bar dark red, status lines spell out losses.
- Walker speed note: at drive cmd 2.2 the gait caps effective speed at ~1.63 u/s (stride length x cadence); the limp ratio is measured against the real baseline (0.94/1.63 = 0.58, inside 0.55 +-10%).
- Verification `--breakable-test` (exit 0 = PASS, 17 checks): pod HP 45->19 per 26 hit, break at <=0, debris lowest corner on terrain (y -0.705 vs -0.705), debris static (drift 0.000) while the mech walked 3.3u away; salvo 8->4->denied/0; Atlas arm_R destroyed by REAL AC fire, then its AC/20 silent 5.5s (shots flat); player laser denied with 0 beams; limp ratio 0.585, drag foot deviation from its home slot <= 0.40, good-leg planted diff 0.000; both legs -> disabled + banner; head pool rule 340->290, headless tracking twist 0.32 rad at 0.5s against 0.96 desired, caught up by 2.2s (err 0.000), player crosshair sway max 14.9 px; reset restores parts/HP/debris/rebind and the salvo returns to 8. Proof: proof/break_{pod_fall,debris_rest,atlas_noarm,hud_destroyed,limp,atlas_disabled}.png — all read.

## Roadmap step 4 — realistic terrain (--terrain-test)

- One ground truth, kept: the world is a 257x257 heightfield grid over 170x170u (seed 20261027), generated once in Main.cs from seeded value-noise fBm (5 octaves, rolling hills) + a craggy NW ridge line + a shallow SE valley + a square-falloff mountain ring at the rim (heights -4.4..+24.4). Amplitude is radius-modulated: 22% inside the arena (r<36, max grade 0.075 = 4.3 deg), full by r=62, so the duel core stays gentle while the rim rises. Main.HeightAt is now a bilinear sample of the grid (node self-check: max diff 0.00024 over 66,049 nodes — float32 coordinate dust; the mesh is built from the grid directly and is exact). Mesh, gait/IK, hit model, collisions, debris — everything still samples HeightAt, so nothing forked.
- Look without textures: Main.CreateTerrainMesh() — indexed grid (131,072 tris) whose vertices sit on heightfield nodes, analytic grid normals, vertex colors by height+slope+two noise fields (grass patches/dry tint, dirt on mid slopes, rock on steep, pale summits), one vertex-color material. Adopted by MechDuel, Main, TimberwolfTest, WormerTest.
- Scatter (MechDuel, seeded 0x5EED): hand-placed 7 trees + 4 buildings unchanged (the (22,8) building still blocks the weapons lane, the (6,16) tree is still the duel-test target), plus 33 scattered trees (40 total; 3 varieties — classic sphere, pine cones, broadleaf; scale 0.85-1.6; low-segment meshes) and 25 squashed-icosphere rocks. Every scatter prop registers a collision circle + HitModel cylinder (70 prop circles total). Placement rejects the duel/weapons/breakable lanes and all spawn/teleport pads, caps tree slope/height; world clamp 47 -> 80.
- Sky/light: ProceduralSkyMaterial gradient, sky-sourced ambient + reflections, ACES tonemap, exponential fog 0.0021 (first pass at 0.0048 + ambient 0.9 washed the vista to pastel — tuned from the proof frames), sun with shadows (320u shadow distance). - Perf (engine-reported, ground-duel frame): 296 draw calls / 414,016 primitives / 296 objects. Terrain 131k tris, mechs ~305k, scatter ~8k. Grass tufts skipped (optional in the brief; draw calls already ~300).

## Roadmap step 5 — character textures (both mechs, baked PBR)

- Route: Cycles bake (not the UV-space fallback). Build scripts (~/workspace/timberwolf/build_timberwolf.py, ~/workspace/atlas/build_atlas.py) now call the shared ~/workspace/mechtex.py: Smart UV Project per part (66°, small island margin), then a procedural surfacing group evaluated in OBJECT space (so weathering flows across part boundaries) — Voronoi panel tint cells + darkened cell borders, Geometry-pointiness edge wear (lighter + smoother), crevice grime + downward streak noise weighted toward the ground, fine micro-noise. Albedo/roughness bake as Cycles EMIT passes (network routed to Emission, 1 sample, deterministic); the normal map bakes from a bump material driven by the same height field (micro noise − panel lines + wear). Bake targets pre-filled with the base coat (use_clear off), so inter-island gaps read as flat coat, never black.
- Sets: per part albedo + roughness (half res) + tangent normal. Torso 2048², parts ≥3.5u 1024², small parts (toes/pins/antenna) 512².
